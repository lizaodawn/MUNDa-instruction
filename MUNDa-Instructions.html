MUNDa Instructions

01 About MUNDa

MUNDa is a spatial analysis platform for data annotated in ENTMARKUS, COMARKUS and IMMARKUS. It imports XML files exported from X-MARKUS, allowing the data to be displayed and explored in an interactive GIS environment, complete with various topographic and historical administrative layers, that preserves their context and also allows for AI-assisted analysis of the spatial data.

MUNDa also allows for the visualization of spatial data in TSV and similar formats.

For more information, source code, and citation details, visit the information section in MUNDa.

The Interface

When you open MUNDa in the browser, a map appears in the main content area, displaying imported data. The interface provides two main sets of controls:

  • Left Menu bar: Menu buttons to import, search and export data, and to modify map symbol settings, language options, and project information.
  • Map Selection: Select a base map, show or hide historical map overlays, and adjust their opacity. Additional overlays are available through WMTS (Web Map Tile Service) services.

Left Menu Bar

Use the icons on the left menu bar to access the following features:

Import Data: Upload a file in XML, TSV, JSON or Excel format, or paste tabular data for spatial exploration. Once the data is imported, a filtering and navigation panel appears on the right. For more information, see Importing Data.

Table Search: Search place names in imported records or the OpenStreetMap database, or filter individual table columns by keyword. For more information, see Table Search in Searching and Filtering Data.

Time Range: Filter records by a selected period. The time range is based on event time for event datasets, or on the publication time recorded in the metadata if event time is unavailable or the dataset is not event-based. You can download the time-filtered records or add them directly to the map as a new layer. For more information, see Searching and Filtering Data.

Export: Export the full imported dataset or a filtered subset in TSV, JSON, or Excel format. You can also export the map as a PNG image. For more information, see Exporting Data.

Map Marker Settings: Adjust the appearance of markers for imported records and filtered results. For more information, see Adjusting Display Settings.

Change Language: Select the interface language. Available languages are English, Traditional Chinese, Simplified Chinese, Korean, and Japanese.

Information: View project information and citation details.

02 Preparing Your Data

X-MARKUS XML Files

Prepare an .xml file exported from X-MARKUS containing either the complete X-MARKUS dataset or a filtered subset. In X-MARKUS, files can be exported in three ways:

  • After converting annotations: Download the complete converted dataset as an.xml. For more information, see Converting Annotations.
  • From the Searching and Filtering interface: Apply filters to the converted dataset, then click export xml to download the current results. For more information, see Visualizing and Exporting Filtered Annotations.
  • From the Visualizing Relations interface: Apply the required graph filters, then click XML to download the filtered subset. For more information, see Exporting the Graph.

Tabular Data

Prepare a table with field names in the first row and one record per row. Coordinates must use WGS84 decimal degrees.

Field Description
id Record identifier.
x Longitude.
y Latitude.
date Date in YYYYMMDD format.
text Descriptive or source text.
place Place name.
url Link to an external resource.
img Image URI; separate multiple URIs with spaces.

Additional columns can be included as needed. For details, see the DocuGIS Tabular Data Specification.

03 Importing Data

Annotation data can be imported to MUNDa by uploading a file or pasting tabular data into the Import Data dialog.

Importing Data Files

Upload an XML, TSV, JSON, or Excel file through the Import Data dialog. The following instructions use an XML file as an example.
  1. Click the Import Data icon in the left menu bar to open the import dialog.
  2. Click Drag or click to upload a file and select your XML file.
  3. Click Parse XML.
  4. Select the coordinate source for event and/or image locations:
    • Event Coordinates: Choose annotated event locations or locations recorded in the metadata.
    • Image Coordinates: Choose from locations recorded in the metadata or a location field set by the user in the IMMARKUS data model.
  5. For IMMARKUS datasets, specify a prefix for the annotation tag group displayed in the filter panel. The default prefix is IMG.
  6. Click Conversion.
  7. Enter a data layer name or keep the system default, then click OK.
  8. The parsed data appears as a table in the preview area of the import dialog. Click Import to add it to the map.
  9. Repeat the process to import additional files as separate data layers. In the data layer panel in the lower-right corner, you can:
    • Tick or untick a layer name to show or hide it on the map.
    • Remove the data layer by clicking the delete icon.

Pasting Tabular Data

Copy tabular data, including the header row, from a TSV file, Excel spreadsheet or Google Sheets document and paste it into the input area in the Import Data dialog.

  1. Click the Import Data icon in the left menu bar to open the import dialog.
  2. Paste the copied content into the data input area.
  3. Click Import to add the data to the map.

04 Navigating the Map

Showing Data Density with Heatmap and 3D Bars

When multiple records share the same location, MUNDa displays them as a single marker. To compare record density across an area, use the heatmap or 3D bars view.

  • Heatmap: Click the heatmap icon in the left-hand toolbar to display record density in the current view. Areas with more records appear in warmer colors.
  • 3D Bars: Click the 3D bars icon in the left-hand toolbar to display a bar for each area. Bar height corresponds to the number of records. Hover over a bar to see the number of records at that location.

Viewing Data Point Details

Click a marker to open the Info panel on the right side of the map and view annotation records at that location.

For event records, the Info panel shows the event tag list, inscription text, comments, and metadata recorded by the user. You can also display all entity tags set by the user in the inscription text.

For image records, the Info pane shows the image, along with the subfolder and image metadata recorded by the user. You can also highlight annotated regions according to the tags set by the user to view their properties.

When no filter is applied, the Info pane shows only the first record at a location. To view all records or records that meet specific criteria at one or more locations, first apply a Tag filter or Map filter to the dataset. For more information, see Searching and Filtering Data.

05 Searching and Filtering Data

Map Search

MUNDa provides two ways to search for records on the map: Tag filters and Map filters. You can view the filtered results in different filter modes, conduct AI-assisted analysis on the filtered results, and view the individual annotation information in the Info pane (for more information, see Viewing Data Point Details).

Searching Imported Records with Tag Filter

The Tag Filter mode provides three tabs for filtering, searching and exporting records.

After you apply a filter, MUNDa highlights matching records on the map. When multiple records appear at a location, MUNDa groups them into a numbered cluster.

Zoom in to expand clusters into individual markers, then click a marker to view its annotation details in the Info pane.

  • Filter Tab
    • Hierarchical Filtering: Use the tag-category dropdown to filter records by their annotation tags. Navigate through the tag hierarchy and select the tag values you want to include.

      • The total number of records matching your selection appears at the bottom of the hierarchical filter section.

      The shortcut icons next to the tag-category dropdown let you adjust tag selections and reload or clear filter data:

      • check_box Select All: Select all values in the current tag category.
      • check_box_outline_blank Clear All: Clear the current tag selections.
      • swap_horiz Invert Selection: Invert the current tag selections.
      • database Load All Data: Reload all data for filtering.
      • delete_sweep Reset: Clear filter conditions.

    • Advanced Filtering: Use a combination of tag selections or keywords to filter records.
      1. Choose Hierarchy Builder or Keyword Search to build a new condition.
      2. Select a tag category or enter a keywordfor each condition. For hierarchy builder, if the tag has a hierarchical structure, you can select subcategories level by level.
      3. Click Add to Pool to add the condition to the Filter Pool.
      4. In the Filter Pool, choose Match ANY (OR) or Match All (AND) to combine the conditions.
      5. Click Search Data to apply the filters and view the matching records on the map.

      You can click the restart_alt icon in the upper-right corner of the advanced filter section to reset the filter conditions, or click location_off icon to hide the markers on the map.

  • Search Tab: In the Search Tab, you can search the entire dataset for keywords in text or image annotation tags, the full text of textual records, or image metadata. Choose one of two search modes:
    • Annotation Tag Keyword Search: Enter a keyword to search only within text or image annotation tags, including tag categories and normalizations.
    • Document Keyword Search: Enter a keyword to search the full text in textual datasets or the metadata in image datasets.

      • In both modes, MUNDa displays the number of matching records and their percentage of the entire dataset below the search bar and highlights them on the map.

      Use the following icons to manage your search and results:

      • search: Run the search.
      • location_off: Clear the marker highlights on the map.
      • backspace: Clear the keyword input.
      • layers: Add the search results as a new data layer on the map.

  • Export Tab: In the Export Tab, you can export filtered results as a new data layer on the map or as a file in TSV, JSON, or KML format. You can also export the entire dataset in TSV or EXCEL format.

Searching Imported Records with Map Filter

In the Map Filter mode, use the spatial lasso to draw an area on the map and filter the records within it. You can browse the matching records in either the Metadata View or the Event View.

In Event View, you can also explore tag distributions through various infographics.

  • Metadata View

    • Metadata Viewopens by default and lists records in reverse chronological order based on the publication year recorded in their metadata.

    1. Toggle on the spatial lasso at the right top corner on the map.
    2. Draw a shape around your area of interest to filter the records. The matching records appear in the timeline.
    3. Click on a record on the timeline to view its details.
  • Event View

    • Event View lists records in reverse chronological order based on the event time annotated by the user in COMARKUS. You can also explore tag distributions and further filter the records through interactive charts. For image datasets without event times, you can still use the tag statistics panel to explore tag distributions.

    1. Click the second tab in the Map Filter pane to switch to Event View.
    2. Select a tag in the first tag pool to explore its distribution within the matching records. If the tags set by the user have a hierarchical structure, a new pool shows the selected tag's child categories. Continue selecting tags to explore deeper levels of the hierarchy.
    3. Choose a chart type to view the distribution at the current level: Bar, H-Bar, Pie, Donut, Line, or Radar.
    4. Hover over a chart element to view the tag counts and the number of records associated with it.
    5. You can expand the Details section below the chart to see each tag's total occurrences, the number of records containing it, and its percentage of the matching records.
    6. Click a chart element to filter the records by the corresponding tag category. You can also export the filtered results as a new data layer or download them in TSV format.

  • Reset

    • Click the Reset button to clear the current map filter area and display all records on the map.

Table Search

Besides exploring records on the map, MUNDa also presents imported data as a table, giving you an alternative view of your records. In the data table, you can view record details, search and filter values by column, and export the results. You can also search the place names in the OpenStreetMap database.

  • Navigating and Filtering Records in the Data Table

    • Click the search iconsearch in the left-hand toolbar to open the data table, where each row is a record and each column is a field. You can then:

    • Search the table data in the data tool. The matching records appear on the map, as in the Search Tab feature in Map Search.
    • Click a row to view the record's details in the Info pane.
    • Hover over a cell to preview its full content.
    • Type in the search field of a column to filter the table by that column's values./li>
    • Export the whole or filtered table in TSV or Excel format.
  • Searching Place Names

    • MUNDa integrates the OpenStreetMap database, so you can search for any place name, view its location on the map, and see the details retrived from the database in the Info pane. This includes place names that appear in the data table.

    1. Click the search icon search in the left-hand toolbar to open the data table dialog.
    2. In the Data Tool section, select OSM Database.
    3. Enter a place name in the search field, then press Enter or click the search button.
    4. MUNDa marks the results on the map. Click a marker to view its details in the Info pane.

06 Adjusting Display Settings

Click the settings icon in the left-hand toolbar to adjust the appearance of markers on the map.

Regular Marker Appearance

Regular markers represent the individual records of imported data. Customizing their appearance helps you distinguish between batches of imported data in different layers. You can adjust the following settings:

  • Marker Color: Choose a color from the palette or enter a hex code.
  • Marker Shape: Select a shape from the dropdown menu.
  • Marker Size: Enter a number to set the size. A larger number produces a larger marker.

Filtered Result Marker Appearance

You can set a different marker style for filtered results to distinguish them from regular markers on the map. To enable these settings, tick the "Search Marker Settings" checkbox.

07 Exporting Data and Maps

MUNDa provides several options for exporting your data and maps. You can export the entire dataset, filtered subsets, or map images.

Exporting All Data

After you import your annotation data, MUNDa converts it into a data table. You can export the entire converted dataset in TSV, JSON, or EXCEL format for later use or for integration with other tools.
  1. Click the icon to open the export options.
  2. Choose the desired export format, then export the data.

Exporting Filtered Data

After applying a filter in Map Search, Table Search, or Time Range Search, you can export the filtered results as a new data layer on the map or as a file in TSV, JSON, or KML format. You can use these files later or integrate them with other tools.

  • Export as Data Files
